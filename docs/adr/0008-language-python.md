# 0008. Language is Python

**Status**: Accepted
**Date**: 2026-09-18

## Context
LEAN and NautilusTrader both expose Python, as does every supporting tool in the reuse map.

## Decision
Python, pinned to a version both engines support.

## Consequences
One language for rubric, adapters, scripts, and tests. The pinned version is reviewed when an engine is upgraded.
